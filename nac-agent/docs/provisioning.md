# Provisioning lokal (belum production-ready)

Root tetap `C:\ProgramData\eGuard NAC`; `bootstrap.json` adalah envelope bertanda tangan opaque, `state.json` berisi schema v1 (`version`, `binding` issuer/device/tenant/site/enrollment, `durable_floor`, `journal_path`), dan `journal.db` pada path tetap. Tidak ada rahasia atau private key di state. Pin bootstrap **di luar payload dan disk**, disuntikkan lewat `-ldflags '-X eguard-nac-agent/provision.BootstrapPinHex=<64 hex lowercase>'`; tanpa pin valid `Pin`, `Write`, `Load` menolak. Operator harus mengendalikan build dan rotasi pin.

Installer admission-gated harus memverifikasi bootstrap (`bootstrap.Verify` dengan Pin, binding, floor dan JournalPath), autentikasi enrolment, dan otorisasi Replace **sebelum** memanggil `Write`. `Replace` hanya flag transient pada argumen State, bukan disimpan; state pengganti tetap tidak boleh menurunkan floor atau mengganti binding (perubahan binding memerlukan alur enrollment terpisah yang aman). `Write` membuat journal hanya jika state belum ada; service memakai `Load`, lalu `bootintegration.Build` dengan callbacks terpercaya; tidak boleh memanggil Create pada boot. `RaiseFloor` menolak angka lebih kecil, memakai rename temp dalam direktori sama. Serialize penulis lintas-proses lewat installer: mutex Go hanya lokal proses; tidak ada transaksi lintas dua file dan crash/power-loss dapat meninggalkan pasangan file berbeda. Atomic rename bukan bukti rollback-protected floor terhadap administrator/SYSTEM/offline disk. Tidak boleh klaim rollback protection hardware atau readiness sebelum ditangani.

Windows memeriksa reparse pada semua komponen path serta owner/DACL pada root dan file yang dibaca; ACE tak dikenal ditolak, write/delete/WRITE_DAC/WRITE_OWNER untuk non-SYSTEM/admin ditolak. Root/file baru diberi DACL protected SYSTEM+Administrators full dan Users read/execute. Caller wajib memastikan journal path dan ACL terus diverifikasi sebelum Open; ACL check-to-use bukan handle-pinned, dan journal sendiri tidak dibuat transaksional dengan state. Temp root Windows integration test harus dijalankan elevated dengan `EGUARD_NAC_PROVISION_ITEST=1` pada tester disposable. Linux unit tests bukan bukti ACL Windows atau layanan SCM. Tidak ada instalasi/deployment di sini.
