# Validasi Windows — BELUM DIJALANKAN

Hanya gunakan VM Windows 11 x64 snapshot disposable dengan izin eksplisit, tanpa server production. Tidak ada akses remote Windows pada slice ini. Binary `TEST-UNSIGNED` tidak boleh dipasang sebagai service; kode collector masih kandidat cross-build. Tidak ada PowerShell/cmd yang dieksekusi oleh agent. Script PowerShell di bawah hanya untuk operator VM.

1. Pada VM dengan Go 1.26+ dan dependency Go cache yang sudah tersedia, copy source tanpa secrets. Build `go build -o dist/eguard-nac-inspect-TEST-UNSIGNED.exe ./cmd/nac-inspect` di VM atau salin hasil cross-build Linux. Jangan jalankan NSIS inspection-only sebagai bukti installer.
2. Standard user (tanpa UAC elevation): dari root repo jalankan `powershell -NoProfile -ExecutionPolicy RemoteSigned -File scripts/windows/validate-collector.ps1`. Script `go test -count=1 -v ./collector ./core ./boundary` dan mengeksekusi inspeksi read-only; hanya menulis snapshot yang mengandung MAC/IP/domain/vendor ke `%TEMP%\nac-go-<GUID>`, lalu menghapusnya pada finally. Pastikan tidak ada SKIP; bila provider tidak ada, nilai Unknown dan reason, bukan memaksa PASS sinyal. Jangan unggah snapshot ke log publik.
3. Pada VM joined-domain terisolasi (jika diizinkan), cocokkan `part_of_domain` dengan NetGetJoinInformation, `domain` dengan sistem, `match=unknown` karena expected signed domain belum tersedia; workgroup `no`. Periksa native `GetIpForwardTable2(AF_UNSPEC)` default IPv4 **dan** IPv6 route terhadap `Get-NetRoute -DestinationPrefix 0.0.0.0/0,::/0` (perintah operator VM read-only, jangan jalankan pada host). Tanpa route atau query gagal berarti `route_status=unknown`, bukan No. Periksa `os=windows-<major>.<minor>.<build>/amd64` terhadap `Get-ComputerInfo OsBuildNumber` (operator VM saja). Periksa beberapa adapter fisik dan vEthernet/VPN dengan Device Manager; konflik tetap unknown. Bandingkan firewall domain/private/public melalui Windows Security GUI; COM failure harus Unknown.
4. VM dengan Defender aktif dan VM dengan Defender pasif + AV pihak ketiga (jika lisensi/izin): bandingkan `SecurityCenter2` inventory dan WMI Defender. Vendor `productState` opaque; jangan klaim running/updated dari bit tanpa kontrak vendor. Passive Defender bukan bukti tidak ada AV pihak ketiga. Ulangi ketika WMI provider error; Unknown tidak boleh jadi No/Yes. Perhatikan nama domain/MAC/IP dan AV adalah data sensitif.
5. Script menjalankan inspector yang melewati boundary subprocess, serta child tetap `--nac-fixed-collect` dari binary service, lalu melaporkan durasi child tanpa raw identitas. Untuk uji timeout saat WMI sengaja terganggu hanya di VM disposable, parent wajib menghentikan child dan tidak meninggalkan proses; bandingkan `Get-Process eguard-nac-*` secara manual setelah tes. **SCM Stop timing NOT RUN**: service tidak boleh dipasang tanpa izin lanjutan. Pengujian SCM/ACL/UAC/upgrade/expiry memerlukan installer fungsional signed dan izin tersendiri; bila kelak diizinkan catat waktu `Stop-Service eGuardNAC` dari operator VM, pastikan kurang dari 12s dan tidak ada child tersisa. Jangan menganggap timing child sebagai timing SCM.

Boundary memakai own executable + stdin anonymous gate sebelum kerja koleksi dan Job Object kill-on-close; bila assignment gagal, child di-kill tanpa dilepas. Jalankan `dist/eguard-nac-service-TEST-UNSIGNED.exe --nac-fixed-collect` tanpa gate hanya di VM: exit nonzero, tidak menghasilkan evidence. Uji Windows VM wajib membuktikan gate parent-crash/EOF, Job assignment, timeout dan tidak ada orphan. Boundary stdout dibatasi 256 KiB, satu child pada satu waktu, tanpa shell atau arbitrary args. Perintah operator VM: `powershell -NoProfile -ExecutionPolicy RemoteSigned -File scripts/windows/validate-collector.ps1`; untuk review route/version tambahan `Get-NetRoute -DestinationPrefix 0.0.0.0/0,::/0` dan `Get-ComputerInfo | Select-Object OsBuildNumber` **hanya di VM**; jangan cantumkan MAC/IP/domain asli ke log publik.

Artefak yang diminta dari operator VM: output test tersanitasi (nama test/PASS/SKIP, exit code), hasil check manual per profile tanpa MAC/domain/nama vendor asli, durasi stop/timeout, OS build, `Get-AuthenticodeSignature` (harus NotSigned), SHA256 binary. Semua nilai identitas fixture sensitif tinggal di TEMP dan dihapus. **Status saat ini: Windows runtime NOT RUN, SCM/UAC NOT RUN, Authenticode signing NOT DONE.**
