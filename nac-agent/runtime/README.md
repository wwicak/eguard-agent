# Runtime coordinator — unwired prerequisite

`Coordinator{Store, Keys, Binding, Now, Collect, Send, Interval, Backoff, CollectTimeout, SendTimeout}` accepts an existing journal and trusted public keys. `Now func() (time.Time,error)` **must** be caller-provided trusted/rollback-evaluated time; raw `time.Now` is not authorization evidence. Both operation timeouts must be positive or `Tick` fails closed. Parent context may impose an earlier deadline. `Tick` verifies complete signed history with `lifecycle.Recover`, then independently verifies signed latest session expiry, before collecting and immediately before sending. The signed epoch expiry minus trusted Now yields a **duration**, combined with the configured operation timeout through `context.WithTimeout`; it is never passed as a local absolute wallclock deadline. The initial remaining budget is also reduced by monotonic elapsed time across both operations, so a subsequent clock sample cannot replenish it. Permanent has no installation expiry but obeys both configured operation timeouts.

`Tick(ctx) (State,error)` is single-flight (`Busy` on overlap). Pending, revoked, cleanup intent/done and verification failures never collect/send; `CleanupIntent` is an observation, not OS deletion permission. Temporary at/after expiry => `Expired`. Collect failure or stale/future evidence => `Stale`; send failure => `Outage`. It does not replace `ObservedAt` or invent freshness. `Run` ticks serially with cancellable interval/backoff, without automatic retry of the same transport submission. Sender receives a context whose deadline can cancel an in-flight cooperative HTTP call; cancellation **cannot stop an uncooperative provider**, does not interrupt already-transmitted bytes or retroactively revoke server acceptance. Tick waits for dependencies to return, never abandons a goroutine or claims hard-kill.

Caller must keep Store/Keys/Binding and dependencies stable while running; provision signed enrollment/bootstrap and trusted clock; wire bounded `Collect` (Windows boundary helper) and `Send` (authenticated transport) that honor context. `cmd/nac-service` still does NOT import this package; no service, enrollment, cleanup, or enforcement wiring supplied. Tests use ephemeral genuine Ed25519 signatures and real lifecycle.Accept/Recover with temporary bbolt journal; no live network. Windows runtime NOT RUN; no installer acceptance.
